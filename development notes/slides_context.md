# Slides context

This file contains an index of context files for AI agents.

## The project

We will generate figures for a presentation about the features of our extension of the software Asymmetree.

The workflow consists on taking a pdf file with some drawings made by hand, and generating .svg files with a recreation of my draft. More details below.

## Wrokflow rules

AI cannot manipulate files unless specified below, or by human in the prompt.

The workflow is a to-do list, it describes the tasks that has to be addressed, only human may define when to start performing one task.

AI can mark tasks as done.

The outputs will be generated in the directory  [figures for slides](figures for slides).

## Context files

- Formal language:  [Math and Algorithms.md](Math and Algorithms.md).

  This file contains the formal mathematical description of our implementation.

  The generated material have to attach to this text.

- hand-made figures [draft_figures.pdf](draft_figures.pdf).

  This pdf file contains a hand.made draft of the figures to generate.

  This pdf contains the sketch for 7 figures, they are enumerated only for reference.

  Note we draw evolutionary scenarios in two formats: (i) one tree embedded in another, and (ii) two trees related by a map

- Sketch content description: [slides_sketch_content.md](slides_sketch_content.md).

  First-pass description of the 7 sketch sections in reading order, including
  content cues, accent colors, and pencil-style notes for later SVG work.

- Example old .svg files:  [old_figs/](old_figs/) 

  This directory contains material previously generated by me.

  Use this if needed to plan the recreation of the figures.

  These figures contain evolutionary scenarions and graphs. Focus on the evolutionary scenarios as 'one gene embeded inside of the other'

- Logos:  [logos](logos) 

  Logos of tools we use

- AI documentation of progress:  [slides_progress.md](slides_progress.md) 

  AI agent should write here important notes after performing a task. They have to be concise but informative enough to allow humans to easily track progress and design decisions.
