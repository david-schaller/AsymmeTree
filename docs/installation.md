# Installation

AsymmeTree requires **Python 3.10 or higher**.

## From PyPI

```bash
pip install asymmetree
```

## From source

```bash
git clone https://github.com/david-schaller/AsymmeTree.git
cd AsymmeTree
pip install .
```
